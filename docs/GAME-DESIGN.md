# OInurturning 游戏规划总纲

> 版本：v0.1（2026-08-26）
> 本文档是对根目录 `InitPlan` 原始策划草案的正式扩充，记录已经过逐节确认的全部设计决策。

## 1. 项目定位

- **类型**：以信息学奥赛（OI）为题材的学员养成/经营类网页游戏。玩家扮演 OI 训练营的教练，招募并培养学员，安排训练、历练、参赛，逐步建立自己的 OI 强队。
- **规模定位**：朋友/社区小规模服务（数十至数百人）。安全与防作弊做到够用即可，注重玩法完整性与实现速度。
- **形态**：部署于服务器，玩家通过浏览器访问；现实时间驱动的轻挂机节奏。

## 2. 技术选型（已定）

| 层 | 选型 |
|---|---|
| 前端 | React + TypeScript + Vite |
| 后端 | Node.js + TypeScript + Express |

## 3. 核心循环

```
招募学员(花声誉/钱) → 培养(训练/历练/养成道具) → 参赛(剧情/PVP/出题对决)赚 钱+声誉+道具
        ↑                                                        ↓
        └─────────── 讲课变现(学员能力 → 钱+声誉) ←──────────────┘
```

## 4. 资源体系（三层模型）

| 层级 | 资源 | 说明 |
|---|---|---|
| **账号层** | 钱 | 主通货：讲课为主要收入，训练/招募为支出 |
| | 声誉 | 「账号等级」型资源：影响招募质量（弱）、讲课报酬（强），解锁高阶受众档位；开除学员/讲砸课会损失 |
| **学员层** | 六维、代码能力、思维能力、出题能力、天赋、心态、精力、专注力上限、体力恢复效率 | 持久成长属性，见 §6 |
| **行动层** | 体力 | 每名学员上限 **5**，现实时间恢复（速率受体力恢复效率影响）；训练 −1、历练 −1~−3、参赛/讲课按活动扣减；体力耗尽不能参与对应操作 |
| | 精力 | 比赛内的「血条」：代码能力不足时额外消耗；耗尽则弃题；赛后随现实时间恢复 |
| | 专注 | 场内临时资源：初始 0，做题过程中积累，提供全局提速倍率；获取速率受心态影响（心态 ≤0 时专注衰减） |

**时间模型**：体力/精力离线持续恢复，玩家每日上线安排一轮行动即可。

## 5. 全局稀有度序列（统一）

> 修订记录：原 InitPlan 中天赋用「灰绿蓝**橙**红彩」、道具用「灰绿蓝**紫**红彩」，不一致。经确认全游戏统一为：

**灰 < 黄 < 绿 < 蓝 < 紫 < 彩**

- 适用：天赋、道具的稀有度标识与配色。
- 题目特性保留独立的严重度阶梯：**红 < 黄 < 蓝 < 紫 < 黑 < 彩**（InitPlan 原设定）；特性决定奖励稀有度时按档位序映射到统一序列。

## 6. 学员属性

### 6.1 属性总表

能力数值属性（六维 / code / thinking / setting 及各辅助属性）范围为 **1–100**；唯一例外：**心态取值 −10 ～ +10**（可为负，机制见下表）。专注/精力的场内资源量按各自上限单独计量。

| 属性 | 可变 | 说明 |
|---|---|---|
| 姓名 | ✔ 消耗改名卡 | — |
| 性别 | ✘ 固定 | — |
| 天赋 | ✔ 升阶/洗练道具 | 见 §7 |
| 心态 | ✔ 动态±道具增 | 通常 >0；影响专注获取效率；<0 时减少专注 |
| 专注力上限 | ✔ 极低概率成长/道具 | 战斗内专注的天花板 |
| 精力 | ✔ 上限道具/赛后恢复 | 见 §4 行动层 |
| 代码能力 | ✔ 训练/书 | 决定写码速度与精力消耗 |
| 思维能力 | ✔ 训练/书 | 决定理解题意与构思速度 |
| **六维（六个独立数值）** | ✔ 定向训练/书 | 数据结构、DP、数学、图论、贪心、字符串——**各自独立计值，绝不合并为单一数值**；每道题只锚定其中一个维度 |
| 出题能力 | ✔ 书/出题实践 | 决定所出题目的质量与难度；出题所得特性概率增加；对决中的直接战斗属性 |
| 体力恢复效率 | ✔ 极低概率成长 | 体力回复速度系数 |

### 6.2 数值成长曲线锚点

剧情分级对应的「通关所需综合属性」参考值：

CSP-J ≈ 10–20 → CSP-S ≈ 25–40 → NOIP ≈ 40–60 → 省选 ≈ 60–75 → NOI ≈ 75–88 → CTT ≈ 85–92 → CTS ≈ 88–95 → IOI ≥ 90

- 训练收益递减：`Δ = base × (1 − cur/cap)^k`，逼近软上限后收益趋零；突破依赖天赋与道具。
- 招募学员按隐性品质档（普通/良好/精英/天才）决定基础属性期望与天赋数量。

### 6.3 养成操作

- **特殊道具**：概率晋升天赋稀有度（进阶石，§7.3）、洗练天赋（洗练券）、增加心态（定心丸等）、增加精力上限。
- **书籍类强化道具**：定向提升某一维/某项能力（六维书、思维书、代码书、出题书）。
- **开除学员**：扣除声誉；概率回收一张改名卡。

## 7. 天赋系统

### 7.1 稀有度与设计基调

- 六档：灰/黄/绿/蓝/紫/彩。灰色为**负面**天赋；彩色天赋效果非常超标（传说级）。
- 无天赋是合法且常见的；多天赋也合法。

### 7.2 家族关系

- 同名（同系）天赋存在于多个稀有度，区别在于数值幅度或适用范围（如「记忆化·绿」→「记忆化·蓝」效果增强）。
- 家族树在设计上保证：**每个天赋至多一个直接上级**（升阶结果唯一确定）。
- 灰色负面天赋的上级是同名弱化版，升阶链终点为中性或微正面天赋（「净化」路径）。

### 7.3 进阶石升阶规则

1. 前提：天赋表中登记了该天赋的上级形态，否则不可升阶（无论当前稀有度多高）。
2. 消耗（按目标稀有度）：灰→黄 **1**、黄→绿 **2**、绿→蓝 **3**、蓝→紫 **5**、紫→彩 **8**（单天赋灰到彩共 19 颗）。
3. 必成功、无失败机制；彩为顶点。
4. 获取渠道刻意稀缺且**商城不直售**：剧情正赛里程碑（一周目共 10 颗）、NG+ 每层全通固定 +5 颗、历练机缘类事件、PVP 奖励（管理员配置，建议冠军 2 颗）。
5. 平衡目标：一周目＋NG+ 三层 ≈ 25 颗，恰好供出**一个**紫→彩天赋——彩天赋保持全服稀缺。

## 8. 比赛模拟引擎（中心机制）

### 8.1 排名制模拟赛（用于剧情模式）

即时结算，逐题模拟：

1. **题目参数**：主导六维、六维需求 D、思维量 M、代码量 C、特性（可选）、分值、时限。
2. **三缺口模型**：对每题计算 六维差(D−学员对应六维)、思维差(M−思维能力)、代码差(C−代码能力)；缺口越大耗时越长（sigmoid 映射）；代码缺口额外消耗精力。
3. **专注机制**：做题过程积累专注，全局提速倍率随专注上升；心态 ≤0 时专注增长打折或衰减。
4. **结果判定**：带随机性的 AC / WA(+20min 罚时、心态下降) / TLE / 弃题（精力耗尽）；特性引入额外扰动（如特定特性加重罚时）。
5. **结算**：时限到/精力尽/做完 → 按总分对 NPC 选手池排名 → 发奖。
6. 比赛仅给微量实战成长；主要成长来自训练，保住培养主循环的地位。
7. 产出：**战报**（逐题时间线、用时、判定、得分、名次、奖励、心态变化）。

### 8.2 出题对决（用于 PVP 与历练遭遇战）

```
第1局 B答A题 → 第2局 A答B题 → 第3局 B答A题 → 第4局 A答B题   （各出2题、各答2题）
```

- **每局计分**：答题方限时解题——解出 → 答题方 **+1**；未解出 → 出题方 **+1**。
- **【考察出题质量】规则**（部分事件启用）：未解出 → 出题方 **+2**。
- **出题端**：题目由出题学员的出题能力生成基准数值（需求值/代码量/思维量），并指定主考六维，可附带特性。
- **答题端**：答题学员对应六维/思维/代码 vs 题目数值，sigmoid 概率判 AC/WA/TLE。
- **平局分流（各场景自定义侧重点 `tiebreak`）**：
  - PVP：进入**加赛**（突然死亡局，先失分者负）；
  - 历练：由具体事件定义（比剩余精力 / 比出题质量 / 友谊收场等，见事件表）。
- **题库联动**：「出题」行动产出的**预制题**可携带上场，替换指定局的临场生成题以保证质量。

## 9. 训练系统

- **基础训练**：随机提升六维之一；**定向训练**：消耗对应书籍，大幅提升指定维度。
- 消耗：钱（随学员数线性增长）＋ 体力 −1。
- 收益递减曲线见 §6.2；极低概率附带心态、出题能力、专注上限、体力恢复效率的成长。
- **专项训练（题库联动）**：消耗自制预制题进行针对性训练，效率高于普通定向训练。

## 10. 历练系统

- 体力投入 −1/−2/−3 三档；先按投入档过滤事件层，再在各稀有度权重池抽取——**投入越高，高稀有度权重越大**。
- 六大类别：**对决 / 奇遇 / 试炼 / 机缘 / 麻烦 / 人情**。
- 对决类事件走 §8.2 出题对决；每个对决事件定义自己的平局侧重 `tiebreak` 与是否启用【考察出题质量】。
- 一次性事件带 `once` 标记；其余可重复、带冷却。
- 完整事件表（40 条，按稀有度→体力排序）见 `docs/data/events.yaml`（底稿如下）。

## 11. 出题玩法（题库闭环）

- 派学员**出题**（耗体力）→ 按「出题能力 × 目标六维」生成题目入库（含质量评级与可能附带的特性）。
- 题库用途：① **预制题**带入出题对决替换临场生成题；② **专项训练**（效率高于普通训练）；③ PVP 己方赛场题（对手做你的题，答错你有声誉收益）。

## 12. 高级学院

- **招募**：学院定期刷新学员池（花钱手动刷新）；学员隐性品质档决定属性期望与天赋数；声誉提供小幅属性加成；招募花费随已有学员数递增。
- **讲课**：受众五档——入门组 / 普及组 / 提高组 / 省选组 / 国家队集训队；报酬与声誉产出随档位暴涨。学员能力 ≥ 受众要求方可接单；能力溢出有额外声誉加成；不足强行接单 → 扣声誉。声誉严重影响报酬总额。

## 13. 剧情模式

### 13.1 结构

共 **8 章**：CSP-J → CSP-S → NOIP → 省选 → NOI → CTT → CTS → IOI。每章 4–5 关：热身赛 / 模拟赛Ⅰ–Ⅲ / 正赛；每关一场 §8.1 排名制模拟赛（3–4 题），NPC 对手池由参数化模板生成同场排名。题目数量与难度符合现实递增。

### 13.2 首通奖励模板 v2（现行版）

```
某关首通奖励 = 钱：M[章节] × S[关位]
             + 道具：从该章道具池抽 n[章节] 件（按关位加权）
             + 里程碑道具：仅「正赛」首通固定发放 U[章节]
```

| 章节 | 关数 | M（钱） | 每关道具 | 道具池稀有度 |
|---|---|---|---|---|
| CSP-J | 4 | 500 | 60%概率1件 | 灰 |
| CSP-S | 4 | 1,200 | 60%概率1件 | 灰·黄 |
| NOIP | 5 | 3,000 | 保底1件 | 黄·绿 |

### 13.3 NG+ 与重复通关

- 第 k 层：题目数值需求 ×(1＋0.15k)、特性触发概率 ＋10%·k、特性等级池上移（彩封顶）。
- 首通奖励＝一周目同关奖励 ×(1＋0.5k)（钱部分）；道具池稀有度 k≥2 起上移一档（彩封顶）；**进阶石不参与乘算**，每层全通固定 +5 颗。
- 里程碑道具 U[章节] **仅一周目（k=0）正赛首通发放**；NG+ 层不重复发放 U（含进阶石类与传说礼盒），石头产出由每层全通固定 +5 承担。
- 每层全通发专属徽章；层数无上限。
- 非首通重复通关给名次奖金：M[章节] × 名次系数（冠军 30% / 亚军 20% / 三至八名 10%）。

## 14. PVP

- 管理员后台发布淘汰赛通告 → 玩家报名（锁定出战阵容）→ 服务端定时自动两两进行 §8.2 出题对决 → 晋级树公示 → 决出名次发奖。
- 己方题库可选入赛场（对手答错你有声誉收益）。
- 奖励：tag 获取卡（彩色道具，PVP 独占）＋ 稀有奖励（管理员设定，默认建议冠军含进阶石×2）。

## 15. 背包与道具

- 六大分类：**养成类**（改名卡/进阶石/洗练券/心态/精力）、**书籍类**（六维/思维/代码/出题）、**功能类**（体力药水/专注道具/奶茶/备用网线/防火墙）、**赛事类**（tag获取卡/报名券/礼盒）、**任务类**（情报/线索/勋章）、**材料类**（碎片/材料）。
- 稀有度六档配色遵循全局统一序列（§5）。

## 16. 经济闭环

- **收入**：讲课（主）、比赛名次奖金、历练奇遇、赞助契约（P4）、雇教练代课（Y6）。
- **支出**：训练（随学员数线性）、招募费（递增）、刷新学员池、事件应急开销、书籍购买。
- **校准目标**：中期玩家（5 学员、NOIP 水平）周收支≈持平略正，大件消费靠攒；全部数字集中在 `economy.yaml` 用公式统一管理并做收支模拟验证。

## 17. 用户系统与技术要点

- **配置即数据**：`docs/data/*.yaml` 同时是策划文档和运行时数据源，API 启动时校验并导入 MySQL（配置表：talents/items/problems/events/stages 等）。
