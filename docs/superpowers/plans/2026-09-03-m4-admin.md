# M4 管理端实现计划

**Goal:** 为 PVP 锦标赛提供管理员可控的赛事、公告和审计基础，随后接入玩家报名与调度器。

**Authority:** `docs/ROADMAP.md` M4、`docs/TECH-DESIGN.md` 管理域/PVP 域、`docs/data/economy.yaml`。

## T4.1

- `requireAdmin` 复用 `requireAuth`，每次请求以数据库中的 role 授权；普通用户对所有管理端点返回 403。
- `PvpTournament` 保存规模、报名截止、自动开始时间、奖池和赛事配置，创建动作写 `AdminAuditLog`。
- `AdminAnnouncement` 保存管理员发布内容；审计记录保存 `adminNameSnapshot`，管理员注销后仍可读。
- 用户查询只返回管理所需余额/声誉/角色/封禁状态，不返回密码哈希。
- Web `/admin` 展示赛事、公告、用户查询和审计表格。

## T4.2 Boundary

- 报名时锁定 entry-ticket、单用户报名唯一性、出战学员快照和携带预制题快照。
- 截止时间后禁止新增/修改报名；调度器只读取锁定快照，不重新读取玩家当前学员或题库。

## T4.2 Result

- `/api/pvp/tournaments`、`/api/pvp/tournaments/:id/register` 和报名详情端点已完成。
- 报名快照按客户端题目顺序保存；赛事满员、票据不足、题目质量/归属错误和截止时间均有明确错误。
- Web `/pvp` 只提供报名和锁定快照展示，不提供报名后的编辑路径。
